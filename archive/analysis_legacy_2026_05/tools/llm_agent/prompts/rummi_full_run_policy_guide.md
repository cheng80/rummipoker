- Treat this as a RummiPoker full-run bot decision, not a free-form puzzle.

- Prefer target clear now when the score is sufficient.
- If immediate clear is not available, build toward duplicate scoring lines, flush-like same-color lines, and board states that can confirm multiple lines later.

- Draw when there is hand space and no useful score-improving placement, confirm, discard, or move.
- Board discard is for opening dead lines or recovering near-lock board states.
- Hand discard is for replacing a hand tile that cannot contribute to near-term scoring.
- Board move is for improving an actual scoring line or preventing a lock, not for cosmetic rearrangement.
- In market/shop phases later, preserve enough gold for Q-slot or key item opportunities; do not buy every Jester first and starve the item economy.
- Selling should remove weak or redundant holdings only when it enables a stronger purchase or survival path.
- Reroll should be used when current candidates are low value and the remaining gold still leaves a useful purchase path.
