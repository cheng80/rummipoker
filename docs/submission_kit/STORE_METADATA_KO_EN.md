## English

```text
Rummi Poker
```

Subtitle:

```text

```

Short description:

```text
Place number tiles, build poker lines, and survive a roguelite run.
```

Long description draft:

```text
Rummi Poker is a tile-placement roguelite where you place number tiles on a 5x5 board and score poker-style hands across rows, columns, and diagonals.

Choose when to draw, where to place each tile, and how to set up multiple scoring lines at once. Jesters and Items change each run, while boss rules force you to rethink familiar patterns.

The hands you complete grow during the run. Open Run Info to see which hands are becoming stronger, then plan your next board around that growth.

Rummi Poker is a puzzle and strategy game. It does not include real-money gambling or cash-out mechanics.
```
