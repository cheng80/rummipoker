# 앱 안에서 리뷰를 요청하는 방법

## 언제 요청할까

앱 안 리뷰 요청은 플레이를 끊지 않는 순간에만 띄운다. 전투 중, Market에서 구매하는 중, 정산 애니메이션이 재생되는 동안에는 요청하지 않는다.

추천 트리거:

- 표준 난이도에서 첫 boss 클리어 이후
- 한 run에서 여러 스테이지를 진행한 뒤 메인 화면으로 돌아왔을 때
- 게임오버 직후가 아니라, 새 run 또는 메인 화면 복귀 이후

피해야 할 트리거:

- 첫 실행 직후
- 튜토리얼 중
- 패배 직후 즉시
- 구매/리롤/정산 버튼을 누르는 순간
- 사용자가 명시적으로 닫은 직후 반복 요청

## 구현 메모

- `in_app_review` 패키지를 사용할 경우 플랫폼별 지원 여부를 먼저 확인한다.
- App Store ID와 Play Store package 같은 마켓 ID가 확정되기 전에는 스토어 이동 버튼을 화면에 보이지 않게 한다.
- 리뷰 요청 성공 여부를 게임 보상과 연결하지 않는다.
- 요청 횟수 제한은 로컬 저장 상태로 관리한다.

## 테스트

- iOS Simulator와 Android Emulator에서는 실제 리뷰 UI가 뜨지 않을 수 있다.
- 버튼과 트리거가 앱 흐름을 막지 않는지 확인한다.
- 스토어 ID가 비어 있을 때 예외가 나지 않는지 확인한다.
