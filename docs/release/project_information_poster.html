Rummi Poker Grid

포커 족보를 5x5 빙고 보드 위에서 만들고, 덱빌딩 요소로 run마다 다른 점수 엔진을 구성하는 보드형 로그라이트 게임.

1. 게임의 핵심 정체성

포커 족보

같은 숫자, 연속 숫자, 같은 색, 조합 패턴으로 점수 족보를 만든다.

빙고 라인

보드의 가로, 세로, 대각선 라인을 동시에 관리한다.

덱빌딩 성장

Jester, Item, 특수 타일, 족보 레벨이 다음 전투의 판단 기준을 바꾼다.

가로 라인: 포커 족보 후보를 만든다.
세로 라인: 같은 타일이 다른 족보 후보에 다시 쓰인다.
대각선 2개: 중앙 타일에서 교차하며 overlap 전략을 만든다.

교차점이 중요한 이유

  • 포커 룰: 한 줄 안의 타일 조합으로 족보를 만든다.
  • 빙고 룰: 같은 타일이 가로, 세로, 대각선 라인에 동시에 속할 수 있다.
  • Overlap: 중앙 교차점 타일은 여러 라인의 점수 가능성을 동시에 살린다.
  • 확정 후 설계: contributor만 제거되므로 남은 타일이 다음 라인의 재료가 된다.
포스터 핵심 메시지: 이 게임은 포커를 단순히 한 손패에서 판정하지 않는다. 보드 위 여러 라인에서 동시에 족보를 만들고, 교차점 선택으로 다음 턴의 가능성을 설계한다.

3. 전투 판단 흐름

배치

손패 타일을 보드에 놓아 여러 라인의 족보 가능성을 만든다.

판정

가로, 세로, 대각선을 각각 포커 족보처럼 읽는다.

확정

완성된 족보의 contributor만 제거하고 점수와 보상을 계산한다.

재설계

남은 타일과 새 손패로 다음 라인, 다음 확정, 다음 Market 선택을 설계한다.

4. 덱빌딩이 룰을 바꾸는 방식

Jester

특정 족보, 색상, 확정 방식, 경제 선택을 강화해 run의 점수 엔진을 만든다.

Item / Tool / Gear

드로우, 이동, 버림, 다음 확정 보너스, Market 조작으로 전투와 성장 선택을 바꾼다.

Special Tiles

타일 자체에 효과를 붙여 같은 보드라도 다른 라인 가치와 정산 결과를 만든다.

5. 플레이 루프

전투

보드 위에 타일을 놓고 족보 라인을 만든다.

정산

확정한 족보로 점수, 보상, 제거 타일을 계산한다.

Market

Jester, Item, Tool, Gear, 특수 타일 후보를 구매하거나 교체한다.

다음 Station

강해진 run 상태로 다음 전투와 보스 제약에 대응한다.

6. 기술 정보

기술 스택

  • Flutter: UI와 앱 구조
  • Flame / flame_audio: 게임 렌더링 보조와 오디오
  • Riverpod: 세션 상태 관리
  • GoRouter: 화면 라우팅
  • easy_localization: 다국어 리소스
  • shared_preferences: 설정과 active run 저장

프로젝트 구조

  • logic/rummi_poker_grid: 전투, 덱, 보드, Jester, Item, Market runtime
  • views: title, new-run, battle, market, archive, settings UI
  • services: save/restore, run setup, progression, unlock state
  • providers: Riverpod 기반 세션 상태와 화면 상태
