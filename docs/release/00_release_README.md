# 출시 문서 안내

## 이 폴더는 무엇을 다루나

`docs/release/`에는 출시 준비에 필요한 빌드, 스토어 등록, 스크린샷, 배포 문서를 모아 둔다. 게임 규칙은 이 폴더가 아니라 `docs/core/`에서 확인한다.

이 폴더는 현재 게임 규칙이나 런타임 정책의 source-of-truth가 아니다. 앱 동작 판단은 `docs/current_system/`, `docs/specs/`, 실제 코드/테스트를 우선한다.

## 문서 구성

- `submission_kit/`: App Store, Play Store, 리뷰, 스크린샷, 제출 체크리스트
- `web_build.md`: web build/deploy 절차
- `rummipoker_nas_deploy.md`: NAS 배포 절차
- `APP_STORE_SCREENSHOTS_SKILL_USAGE_KO.md`: 스크린샷 제작 스킬 사용법
- `project_information_poster_image_prompt.md`: 프로젝트 정보 포스터 생성용 원천 프롬프트
- `project_information_infographic.html` / `.png`: 프로젝트 정보 인포그래픽 산출물
- `project_information_poster.html` / `.png`: 프로젝트 정보 포스터 산출물

## 언제 고치나

- 실제 출시 절차나 빌드 명령이 바뀌면 이 폴더를 갱신한다.
- 공모전 제출 이력은 현재 출시 판단 기준이 아니다.
- 구 앱 자료는 Rummi Poker 기준으로 재작성한 문서만 사용한다.
