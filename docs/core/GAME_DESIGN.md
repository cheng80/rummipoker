# Game Design

## 한 줄 정체성

Rummi Poker Grid는 숫자와 색을 가진 타일을 5×5 보드에 배치해 여러 줄의 족보를 동시에 만들고, 겹침을 키워 점수화하는 덱빌딩 로그라이트다.

## 타깃 플레이어와 플레이어 판타지

- 짧은 규칙을 조합해 매 턴 보드 효율을 높이는 퍼즐을 좋아하는 플레이어
- 무작위 후보 속에서 Jester, Item, 타일을 고르고 한 run의 빌드를 만드는 과정을 좋아하는 플레이어
- 한 줄만 완성하는 대신 교차하는 여러 줄을 설계해 큰 정산을 만드는 플레이어

플레이어 판타지는 흩어진 타일을 읽고 배치해 죽은 줄을 살리고, 제한된 행동과 마켓 선택으로 자신만의 점수 엔진을 완성하는 것이다. 포커는 족보 형태를 제공하지만 실제 조작 대상은 카드가 아니라 숫자·색 타일이다.

## 코어 루프

1. 전투 목표와 제약을 확인한다.
2. 타일을 뽑아 보드에 놓고, 필요하면 보드 버림·손패 버림·보드 이동으로 배치를 고친다.
3. 현재 보드에서 점수 족보가 생기면 확정한다.
4. contributor 타일이 제거된 뒤 남은 타일을 바탕으로 다음 겹침을 만든다.
5. 목표 점수를 달성하면 정산하고 Market에서 다음 전투의 빌드를 보강한다.
6. Blind Select에서 다음 전투를 고르고 run을 이어간다.

전투의 정확한 판정은 [GAME_RULES.md](GAME_RULES.md)가 소유한다.

## 디자인 기둥

### 부분 줄도 의미가 있다

보드 한 줄이 5칸으로 가득 차기 전에도 현재 놓인 타일만으로 트리플, 투 페어, 포카드가 성립할 수 있다. 플레이어는 완성을 기다리기보다 현재 기회를 읽고 확정 시점을 선택한다.

### 겹침은 핵심 전략이다

행·열·대각선이 공유하는 contributor는 여러 점수 줄을 동시에 강화한다. 좋은 배치는 단일 고득점 줄보다 다음 보드까지 고려한 교차 구조를 만든다.

### 확정은 보드를 다시 설계한다

확정하면 줄 전체가 아니라 실제 족보 contributor의 합집합만 제거된다. kicker와 죽은 줄의 타일은 남으므로 한 번의 정산이 다음 퍼즐 상태를 만든다.

### 선택이 빌드를 만든다

Jester, Item, 타일 보강, Market 구매와 판매는 플레이어 선택이다. 시스템은 특정 성장축을 자동 지급하거나 자동 사용해 선택을 대신하지 않는다.

## 모드와 현재 범위

- 새 run의 플레이어 선택 난이도는 `표준`과 `도전`이다. `relaxed` ID는 내부 호환용이며 일반 선택지로 노출하지 않는다.
- 현재 플레이 흐름은 New Run → Blind Select → Battle → Settlement → Market → 다음 Blind Select다.
- 전투, 정산, Market, active run 이어하기·재시작, S8 이후 계속 진행, Archive 수집판이 현재 제품 범위에 연결돼 있다.
- 세부 콘텐츠의 전체 행 목록은 이 문서에 복제하지 않는다. 현재 목록은 [CONTENT_CATALOG.md](../generated/CONTENT_CATALOG.md)가 제공한다.

## 성공과 실패 경험

성공 경험은 제한된 타일과 행동으로 둘 이상의 점수 줄을 겹치고, 빌드 효과가 정해진 순서로 합쳐져 목표를 넘기는 순간이다. 전투 승리는 단순한 점수 증가가 아니라 다음 Market 선택과 다음 보드 설계로 이어진다.

실패 경험은 보드가 막히거나 덱·손패가 소진돼 더 진행할 수 없게 되는 것이다. 실패 원인은 플레이어가 다음 run에서 배치, 확정 시점, 버림 자원, Market 구매를 다르게 판단할 수 있도록 읽혀야 한다.

## Non-Goals

- 원페어를 기본 점수 족보로 바꾸지 않는다.
- 포커 카드 이미지와 전통 포커 베팅을 게임의 주 피사체로 삼지 않는다.
- 특정 Jester, Item, 타일 또는 성장축을 자동 지급·자동 구매·자동 사용하지 않는다.
- 저장 schema, 콘텐츠 ID, 광범위한 코드 명칭을 이 문서만으로 바꾸지 않는다.
- 전체 콘텐츠 catalog나 밸런스 수치를 이 문서에 복제하지 않는다.

## 플레이어 용어

| 용어 | 플레이어에게 보이는 의미 |
|---|---|
| 타일 | 색과 숫자, 물리 identity를 가진 배치 단위 |
| 족보 | 한 줄의 현재 타일 조합을 평가한 패턴 |
| 칩 | 족보 기본값과 효과가 더해지는 점수 계산 재료 |
| 점수 +% | 칩에 더해지는 가산형 점수 배율 |
| 점수 ×N | 가산 계산 뒤 적용되는 곱연산 배율 |
| 골드 | Market에서 구매·리롤에 쓰는 run 재화 |
| 확정 | 현재 보드의 모든 점수 가능 줄을 함께 정산하는 행동 |
| 보드 버림 | 보드 타일을 제거하고 배치 공간을 회복하는 제한 행동 |
| 손패 버림 | 손패 타일을 제거하고 다음 타일을 찾는 제한 행동 |
| 보드 이동 | 보드 타일 하나를 빈 허용 칸으로 옮기는 제한 행동 |
| Jester | 조건에 따라 점수·경제·상태를 바꾸는 장착 콘텐츠 |
| Item | 전투·Market·정산·Station 시점에 사용하는 콘텐츠 |
| Station | 플레이어에게 보이는 run 진행 단위; 일부 내부 코드는 `stage`·`blind` 명칭을 유지 |
| Market | 전투 사이에 후보를 확인하고 구매·판매·리롤하는 화면 |
